这个项目是一个以 Python 为核心的本地智能体系统（GGbot），目标是把“大模型对话能力”与“可控的工程执行能力”结合起来：它一方面通过 LiteLLM 对接 OpenAI/兼容模型，支持多轮对话、流式输出、thinking/plan 展示和工具调用；另一方面通过统一工具注册与执行链路，把文件读写、Shell、网页搜索/抓取等能力接入到同一套运行时中，并将每次对话、工具调用、状态事件持续写入 transcript（jsonl）和 session 元数据，做到可追溯、可回放；在交互层既提供 CLI/TUI 也提供 FastAPI+WebSocket 接口，前端可实时接收事件流（assistant_delta、tool_call、tool_result、permission_request 等），后端通过会话级上下文管理与权限审批机制（尤其是 shell_run）保证多会话隔离与执行安全，同时以 workspace 沙箱和配置中心（ ~/.ggbot ）约束运行边界，整体上它不是一个“只会聊天”的助手，而是一个面向真实开发任务的、可观察、可治理、可扩展的 agent runtime。
